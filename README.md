# سندات الإنتاج — شركة النسيم إخوان

برنامج ويب ثابت (HTML + JavaScript) لإعداد سندات إنتاج أبواب الرول، ثم تصديرها إلى Excel بتخطيط سنداتكم الحالي أو نسخ الأكواد والكميات إلى برنامج الشركة.

## التشغيل
- محلياً: افتح `index.html` في المتصفح (Chrome أو Edge). لا يحتاج إنترنت ولا تثبيتاً.
- على GitHub Pages: ارفع محتويات هذا المجلد إلى مستودع، ثم Settings ← Pages ← Deploy from a branch ← main / root.

## الدخول (شكلي)
المستخدمان الافتراضيان: `user1` و`user2`، وكلمة المرور لكليهما `1234`. **غيّرهما قبل النشر.**
التسجيل للفصل بين سندات الشخصين فقط وليس حماية: أي شخص يفتح الموقع يستطيع قراءة `config.js`.
لتغيير كلمة مرور: افتح `tools/hash.html`، اكتب كلمة المرور، وانسخ الناتج إلى الحقل `h` في `config.js` (ويمكن تغيير الأسماء `u` و`name`).

## ترقيم السندات
لكل مستخدم بادئة في `config.js` (الحقل `prefix`): user1 ← `A-0001`، user2 ← `B-0001`، فلا تتكرر الأرقام بين الشخصين.

## حالة السند
- **مسودة**: قابلة للتعديل، وتتبع الكتالوج الحالي (تصحيح وحدة صنف ينعكس عليها).
- **مكتمل 🔒**: مقفل، وتُثبَّت فيه أسماء الأصناف ووحداتها فلا يغيّرها أي تعديل لاحق للكتالوج. يُفتح للتعديل بزر «إعادة فتح».

## المخرجات
- **Excel**: ورقة «الملخص» (إجمالي كل كود موزعاً على الأبواب)، ثم ورقة منسقة لكل باب، ثم ورقة «بيانات» خام بتخطيط السندات القديم للنسخ أو الاستيراد إلى برنامج الشركة. الأوراق المطبوعة مضبوطة على A4 مع ترويسة وتوقيعات وترقيم صفحات، وعمود الكمية معادلة (العدد × الطول).
- **PDF / طباعة**: زر «PDF» يفتح نافذة الطباعة؛ اختر «حفظ بتنسيق PDF». اسم الملف المقترح هو رقم السند وMO.

## أين تُحفظ البيانات؟
السندات وتعديلات الكتالوج تُحفظ في **متصفح كل جهاز** (`localStorage`) ولا تُرفع إلى GitHub. مسح بيانات المتصفح يحذفها، فاستعمل «نسخة احتياطية» بانتظام (تصدير/استيراد ملف JSON).

## الكتالوج
- المصدر الأساسي: `catalog-data.js` (111 صنفاً من كتالوج Excel + 34 صنفاً من البرنامج السابق).
- الأصناف المعلَّمة `sg:1` وحدتها **مقترحة** وتحتاج تأكيداً. تؤكَّد من صفحة «الكتالوج» (تعديل ثم حفظ)، ولتعميمها على الجميع عدّل `catalog-data.js`.
- حساب الكمية: أصناف المتر = العدد × الطول، أصناف القطعة (والمتر المربع والكغم) = العدد فقط.
